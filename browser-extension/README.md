# Claude(claude.ai)의 입력 중 검사 (AI 누리 보안 확장)

> 시연 범위(2026-11-05): claude.ai(Claude Code 웹 포함)에서만 동작한다. ChatGPT는 지원하지 않는다.

PC 앱과 확장이 같은 컴퓨터에서 실행됩니다. 기본 처리 위치인 **서버에서 처리**를 쓰면 Claude(claude.ai)의 프롬프트 편집 내용이 입력 중 팀 서버로 전송됩니다. 팀 서버의 인증서와 토큰은 PC 앱에서 설정합니다. **이 PC에서만 처리**를 선택하면 로컬 엔진으로 검사합니다.

1. 이 브랜치의 프로그램을 실행합니다. 팀 서버의 실시간 위치 API는 `POST /process/preview`입니다 ([backend #58](https://github.com/team-i-balance/backend/pull/58)).
2. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 **개발자 모드 → 압축해제된 확장 프로그램 로드**로 이 `browser-extension` 폴더를 선택합니다. Firefox 개발 테스트는 `about:debugging#/runtime/this-firefox`에서 **임시 부가 기능 로드**로 `manifest.json`을 선택합니다.
3. PC 앱의 **설정 → 브라우저 연결 코드 복사**를 누릅니다. 확장 아이콘을 열어 코드를 붙여넣고 **연결**을 누른 뒤 Claude 탭을 새로고침합니다.

입력·붙여넣기·한글 조합으로 내용이 바뀌면 즉시 검사를 요청합니다. 한 입력창에는 한 번에 한 요청만 진행하며, 응답이 오면 대기 중인 최신 문장으로 이어집니다. 서버는 현재 정책으로 탐지 위치와 유형만 반환합니다. 이 PC의 조직 베이스 값과 기밀 구간은 서버 요청 전에 가립니다.

## 칩 (새 창 없이 칩을 펼쳐 마무리)

- 강조된 단어(옅은 파란 면 + 파란 밑줄)를 누르면 칩 두 개가 열립니다: **마스킹** · **원문유지**.
- **마스킹** → 위에는 바뀔 값만 보입니다(예: `[전화번호_1]`, 지우는 값은 취소선). 아래 칩에서 **적용**(같은 값이 여러 곳이면 모두) 또는 **모두 적용 N**(하이라이트 전부)을 고릅니다. 입력창에서 그 자리만, 입력하듯이 바뀝니다(되돌리기 기록에도 남습니다).
- **원문유지** → 사유 칩 셋: **업무상 필요 · 오탐 · 승인된 개인정보**. 고르면 그 값의 하이라이트가 사라집니다. 오탐은 앱을 끌 때까지 다시 탐지하지 않습니다. 비밀값·기밀은 원문유지를 고를 수 없습니다.
- 끝나면 칩에 결과 한 줄과 **다음 항목 · 되돌리기**가 남습니다. 다른 곳을 클릭하거나 Esc를 누르면 칩만 닫히고 단어 표시는 남습니다.
- **하이라이트가 남아 있으면 Enter(전송)와 전송 버튼을 막고** 첫 항목의 칩을 엽니다. Shift+Enter 줄바꿈은 그대로입니다. 남은 하이라이트가 없어지면 이 입력의 결정(마스킹·원문유지 사유)을 서버에 한 번 기록합니다.
- 실제 AI 전송은 원래 사이트의 전송 버튼이나 Enter로 합니다.

## 확장 아이콘(연결 창)

- **AI 답변 복원 열기**: 페이지 안에 복원 칩을 엽니다. 마지막으로 마스킹해 보낸 입력의 매핑으로 AI 답변을 원래 값으로 바꿉니다(서버는 10분 안에 한 번만 복원).
- **서버 기능 전체**: 현재 팀 서버의 API 목록을 PC 앱에 표시합니다(직접 연 경우에만 창이 열립니다).
- **해제**는 해당 브라우저 연결을 지웁니다. PC 앱의 **연결 해제**는 연결 코드를 폐기합니다. 서버나 연결 오류가 나면 검사 상태가 입력창 위에 표시됩니다.

글꼴은 Pretendard가 설치되어 있으면 그것을, 없으면 시스템 한글 글꼴을 씁니다.

이 API를 아직 배포하지 않은 서버에서는 기존 `/process` 변환문을 원문과 맞춰 위치를 확인합니다. 이름 등이 붙어 위치를 확정할 수 없는 경우 입력창 위에 안내합니다. 구버전 서버는 검사마다 최대 10분짜리 임시 작업을 생성하므로 반복 입력에는 실시간 위치 API를 권장합니다.
