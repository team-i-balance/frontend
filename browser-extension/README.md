# ChatGPT와 Claude의 입력 중 검사

PC 앱과 확장이 같은 컴퓨터에서 실행됩니다. 기본 처리 위치인 **서버에서 처리**를 쓰면 ChatGPT와 Claude의 프롬프트 편집 내용이 입력 중 팀 서버로 전송됩니다. 팀 서버의 인증서와 토큰은 PC 앱에서 설정합니다. **이 PC에서만 처리**를 선택하면 로컬 엔진으로 검사합니다.

1. 이 브랜치의 프로그램을 실행합니다. 팀 서버의 실시간 위치 API는 `POST /process/preview`입니다 ([backend #58](https://github.com/team-i-balance/backend/pull/58)).
2. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 **개발자 모드 → 압축해제된 확장 프로그램 로드**로 이 `browser-extension` 폴더를 선택합니다. Firefox 개발 테스트는 `about:debugging#/runtime/this-firefox`에서 **임시 부가 기능 로드**로 `manifest.json`을 선택합니다.
3. PC 앱의 **설정 → 브라우저·CLI 연결 코드 복사**를 누릅니다. 확장 아이콘을 열어 코드를 붙여넣고 **연결**을 누른 뒤 ChatGPT 또는 Claude 탭을 새로고침합니다.

입력·붙여넣기·한글 조합으로 내용이 바뀌면 즉시 검사를 요청합니다. 한 입력창에는 한 번에 한 요청만 진행하며, 응답이 오면 대기 중인 최신 문장으로 이어집니다. 서버는 현재 정책으로 탐지 위치와 유형만 반환합니다. 이 PC의 조직 베이스 값과 기밀 구간은 서버 요청 전에 가립니다.

- 강조된 단어를 클릭하면 칩이 열립니다. 다른 곳을 클릭하거나 Esc를 누르면 칩이 닫히고 단어 표시는 남습니다.
- **가릴 항목 선택**에서 체크된 항목을 가린 뒤 **입력창에 적용**합니다. 실제 AI 전송은 원래 사이트의 전송 버튼을 사용합니다. 위치를 확정할 수 없는 항목과 비밀값은 빠른 선택에서 계속 가립니다.
- **상세 점검**에서는 놓친 항목 신고와 조직 정책상 차단된 부분을 검토할 수 있습니다. **엑셀 보호**와 **설정**은 PC 앱에서 열립니다.
- **답변 복원**은 최근 적용한 변환문의 매핑을 사용합니다. 하이라이트가 없는 상태에서도 확장 아이콘의 **AI 답변 복원 열기**로 접근합니다.
- **서버 기능 전체**는 현재 팀 서버의 API 목록을 PC 앱에 표시합니다. 프롬프트·파일·직원 사유·사건·오탐·로그·정책 기능 등에서 작업과 매개변수를 선택해 실행합니다. 각 작업은 앱에서 설정한 토큰 권한으로 실행됩니다.
- 확장 아이콘의 **해제**는 해당 브라우저 연결을 지웁니다. PC 앱의 **연결 해제**는 연결 코드를 폐기합니다. 서버나 연결 오류가 나면 검사 상태가 입력창 옆에 표시됩니다.

이 API를 아직 배포하지 않은 서버에서는 기존 `/process` 변환문을 원문과 맞춰 위치를 확인합니다. 이름 등이 붙어 위치를 확정할 수 없는 경우 상세 점검을 안내합니다. 구버전 서버는 검사마다 최대 10분짜리 임시 작업을 생성하므로 반복 입력에는 실시간 위치 API를 권장합니다.
