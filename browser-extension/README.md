# ChatGPT 입력창 감지 프로토타입

Chrome에서 `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → 이 폴더를 선택한 뒤 `https://chatgpt.com/`을 새로고침한다. 페이지 오른쪽 아래에서 감지 상태를 확인한다. 페이지가 바뀌면 선택자가 달라져 감지하지 못할 수 있다.

현재 입력창의 존재만 확인하며 입력 텍스트를 읽거나 저장하거나 전송하지 않는다. 로컬 검사 연동, 전송 차단, 가명화 및 복원은 구현되지 않았다. 이 표시를 전송 보호나 검사 완료로 해석하면 안 된다.
