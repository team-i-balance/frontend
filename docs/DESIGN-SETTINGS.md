# AI 누리 보안 — 디자인 설정

회사 정보보호팀이 매일 쓰는 웹 콘솔입니다. 직원이 생성형 AI(ChatGPT·Copilot 등)에 입력한 문장에서 개인정보를 찾아 가린 값으로 바꾸고, 원문이 그대로 나간 건은 보안팀이 판단합니다. 판단은 위반 / 예외 인정 / 오탐 셋 중 하나이고, 재발 방지 규칙은 서명한 뒤 배포합니다.

이 문서만 보고 같은 화면을 만들 수 있도록, 값을 모두 적었습니다.

- **테마**: 다크 하나뿐입니다. 라이트 테마도, 테마 바꾸기도 없습니다.
- **기준 화면**: 데스크톱 1440px. 모바일은 깨지지 않을 정도만 맞춥니다.
- **첨부 로고**
  - `ai-nuri-mark.svg`(파랑), `ai-nuri-mark-white.svg`(흰색), `ai-nuri-favicon.svg`
  - 같은 그림의 PNG 512px
  - 가로 조합 `ai-nuri-lockup-dark.png`, `ai-nuri-lockup-transparent.png`

## 1. 원칙

1. **구조는 면으로 나눕니다.** 패널은 테두리 없이 면 색만 다르게 둡니다. 선은 표 행 사이와 구역 사이에만 씁니다.
2. **파랑(시그널 블루)은 세 곳에만 씁니다.**
   - 고른 것: 옅은 파란 면 + 왼쪽 2px 막대
   - 화면당 주 행동 하나: 채운 버튼
   - 키보드 포커스

   사이드바, 탭, 필터, 차트에는 파랑을 쓰지 않습니다.
3. **글자색은 사실상 두 단계입니다.** 값과 문장은 밝게, 메타와 라벨은 회색으로 씁니다.
4. **판단에 쓰지 않는 정보는 지우거나, 마우스를 올렸을 때 보이는 설명(툴팁)으로 접습니다.** '예시 데이터 / 서버 N건' 같은 데이터 출처는 사이드바 한 곳에만 둡니다.
5. **보안팀은 원문을 보지 않습니다.** 화면에는 가린 값만 나옵니다. 예: `******-*******`, `윤*아`
6. **판단 버튼 셋은 모양이 같습니다.** 색으로 정답을 암시하지 않습니다.
7. **움직임은 위치 전환과 나타남만 씁니다.** 길이는 120~320ms입니다. 튀는 호버 효과는 쓰지 않습니다.

## 3. 글자

글꼴은 **Pretendard Variable** 하나입니다. 숫자는 폭이 같은 숫자(`font-variant-numeric: tabular-nums`)로 맞추고, 한글은 낱말 단위로 줄을 바꿉니다(`word-break: keep-all`).

| 크기 | 쓰는 곳 |
|---|---|
| 12 | 시각, 단축키, 숫자 알약 (이보다 작게 쓰지 않음) |
| 13 | 표 보조, 부가 설명, 작은 버튼, 메타 |
| 14 | 본문, 표 셀 |
| 15 | 이름, 판단 버튼 제목 |
| 16 | 구역·패널 제목, 보낸 문장 |
| 18 | 처리 패널 제목 |
| 20 | 상세 제목 |
| 22 | 화면 제목 |
| 28 | 핵심 수치(흐름도 숫자, 현황 수치, PC 적용) |

굵기는 세 가지만 씁니다. 700·800은 쓰지 않습니다.

| 굵기 | 쓰는 곳 |
|---|---|
| 400 | 본문 |
| 500 | 버튼, 라벨, 칩, 표 머리, 목록 이름 |
| 600 | 화면·상세·구역 제목, 판단 버튼 제목, 핵심 수치, 채운 버튼 |

- 줄 간격은 본문 1.5, 제목 1.3입니다.
- 제목에는 자간 -0.01~-0.02em을 줍니다.
- 600 굵기는 한 화면에 3~4덩어리를 넘기지 않습니다.

## 4. 간격 · 모서리 · 높이 · 그림자 · 아이콘

- **간격**: 4px 단위로 `4 · 8 · 12 · 16 · 20 · 24 · 32 · 36 · 48`
  - 화면 안쪽 여백 24, 구역 사이 24
  - 패널 안 16~20, 묶음 안 8
- **모서리**
  - 2: 가장 작은 부품
  - 6: 작은 버튼, 라벨
  - 12: 버튼, 입력, 상자
  - 16: 패널(최대)
  - 완전히 둥글게: 상태 점, 칩, 토글
- **누르는 것의 높이**
  - 28: 표 안 버튼, 표 안 선택
  - 32: 작은 버튼, 사이드바 항목
  - 40: 기본 버튼, 입력
  - 48: 큰 버튼
- **그림자**: 면은 평평합니다. 떠 있는 것에만 그림자를 줍니다.
  - 팝오버·툴팁·알림: `0 8px 24px rgba(0,0,0,.4)`
  - 대화상자: `0 16px 48px rgba(0,0,0,.55)`
- **아이콘**: 가는 선 아이콘(lucide 계열, 선 굵기 1.5)을 씁니다.
  - 크기는 두 가지만 씁니다: 16(글자 옆), 20(메뉴)
  - 아이콘을 둥근 네모 칸에 넣지 않습니다.

## 5. 부품

### 버튼

모든 버튼은 기본 → 올림 → 누름 → 비활성의 4단계 상태가 있습니다. 비활성은 투명도를 낮추지 않고, 요소 면(`#343A40`)에 비활성 글자색(`#868E96`)으로 바꿉니다.

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 주 행동 | `#3570E0` 채움, 흰 글자 600 | 화면당 하나(예: 서명 후 배포하기) |
| 기본 | `#343A40` 면 + `#59616B` 테두리, 글자 500 | 일반 행동 |
| 강한 테두리 | `#343A40` 면 + `#C1C7CE` 테두리 | 대화상자 확인 |
| 글자 | 투명, `#C1C7CE` 글자 | 취소, 해제 |
| 링크 | 투명, `#8FB5FF` 글자, 올리면 밑줄 | 다른 화면으로 이동 |
| 조용한 | 28px, 투명 + `#3A4148` 테두리 | 표·목록 행 안에서 반복되는 버튼 |

- 크기는 작은 32 / 기본 40 / 큰 48입니다.
- 작은 버튼 글자는 13px, 모서리 6입니다.

### 판단 버튼 (위반으로 기록 · 이번 건 예외 인정 · 오탐으로 기록)

- 세 개를 같은 모양으로 나란히 둡니다.
- 최소 높이 64, `#343A40` 면, `#59616B` 테두리, 모서리 12입니다.
- 제목은 15/600입니다. 그 아래에 결과 설명 한 줄(13px `#C1C7CE`)을 둡니다(예: '위반 이력이 남아요'). 오른쪽 위에는 단축키 숫자 1·2·3을 둡니다.
- 마우스를 올리면 테두리가 `#C1C7CE`, 면이 `#3B4148`가 됩니다.

### 라벨 · 상태 표시

- **라벨**: 높이 20, 모서리 6, 12px, `#3B4148` 바탕.
  - 한 행에 상태 라벨은 하나만 둡니다.
  - AI 이름 같은 메타는 라벨로 만들지 않고 글자로 씁니다.
- **위험 라벨**('원문 전송' 등): 옅은 빨강 바탕에 빨강 글자.
- **상태 점**: 8px 점 + 13px 글자.
  - 위반은 빨강, 종결은 초록, 나머지는 회색 `#868E96`입니다.
- **건수**: 바탕 없는 12~13px 숫자. 알약 모양 배지는 남발하지 않습니다.
- **가린 값**(보낸 문장 안)
  - 원문으로 나간 값: 옅은 빨강 바탕 + 빨강 글자, 모서리 4
  - 변환된 값: 회색 바탕
  - 지운 값: 취소선
  - 오탐 신고 문장 속 잡힌 값: 옅은 파란 바탕

### 안내 상자

- 상태색 테두리 + 옅은 바탕 + 아이콘으로 만듭니다. 제목은 한 줄, 설명은 두 줄까지 씁니다.
- 종류는 다섯 가지입니다: 성공, 경고, 오류, 안내, 할 일(파랑. '배포 대기 변경 N개'처럼 할 일을 알릴 때).

### 알림(토스트)

- 화면 위 가운데에 뜹니다. 패널색 면에 상태색 테두리와 아이콘을 둡니다. 글자는 본문색, 모서리는 12입니다.
- 종류는 완료, 경고, 오류 세 가지입니다.
- 판단 직후에는 되돌리기 알림을 10초 동안 띄웁니다. 버튼은 '되돌리기 Z'이고, 아래에 남은 시간 막대를 둡니다.

### 입력칸 · 선택칸 · 긴 글

- 높이 40, 모서리 12입니다. 상태는 다섯 가지입니다.
  - 기본: `#343A40` 채움, 테두리 없음
  - 마우스 올림: `#59616B` 테두리
  - 쓰는 중: `#C1C7CE` 테두리
  - 오류: 빨강 테두리
  - 성공: 초록 테두리
- 라벨은 13/500입니다.
- 칸 아래 문구 앞에는 아이콘을 붙입니다: 안내(ⓘ 회색), 오류(ⓧ 빨강), 성공(✓ 초록).
- 표 안 선택칸은 28px, 투명으로 두고 마우스를 올릴 때만 면이 보입니다.

### 고르기

- **체크박스**: 18px, 모서리 4입니다. 켜면 `#3D7EF7`로 채웁니다.
- **토글**: 36×22입니다.
  - 켜면 트랙 `#365989`, 손잡이 `#DCE8FA`입니다. 줄지어 있어도 튀지 않게 낮은 파랑을 씁니다.
  - 끄면 트랙은 요소 면에 `#59616B` 테두리입니다.
- **탭·필터**: 알약 칩입니다(높이 32, 테두리 `#59616B`).
  - 고른 칩은 요소 면(`#343A40`)에 본문 글자입니다. 파랑은 쓰지 않습니다.
  - 칩 안의 숫자는 중립색입니다.
- **단계 표시**: 번호가 든 원 + 이름으로 된 알약을 '›'로 잇습니다.
  - 지난 단계는 체크, 지금 단계는 옅은 파란 면 + 파란 테두리 + 채운 번호입니다.

### 표

- **머리**: 바탕 없음, 12/500 회색(`#A3ABB4`), 높이 40.
- **행**
  - 높이 40, 두 줄 행은 48입니다.
  - 행 사이는 `#3A4148` 1px로만 나눕니다. 세로선과 바깥 테두리는 없습니다.
- **여백·정렬**: 첫 칸과 끝 칸은 여백 24입니다. 숫자 열은 오른쪽 정렬에 폭이 같은 숫자를 씁니다.
- **마우스 올림·고름**
  - 마우스를 올리면 행이 `#2E3439`가 됩니다.
  - 고른 행은 선택 면에 첫 칸 왼쪽 2px 파란 막대를 둡니다. 마우스를 올려도 고른 색이 유지됩니다.

### 패널 · 화면 머리

- **패널**: `#25292D`, 테두리 없음, 모서리 16, 여백 20/24, 안쪽 간격 16. 제목은 16/600이고, 제목 옆 부제는 13px 회색입니다.
- **화면 머리**: 작업판을 뺀 모든 화면에 둡니다. 패널 밖 한 줄(높이 40 이상)에 다음을 둡니다.
  - 제목 22/600
  - 회색 메타 13px(예: 'v12 적용 중 · PC 38/40대 · 거부 2대')
  - 오른쪽 도구(탭·버튼)

### 대화상자

- 가운데 대화상자는 폭 520(넓은 것 640), 오른쪽에서 나오는 패널은 폭 480입니다. 모서리 16에 그림자를 줍니다.
- **결론 내기** 대화상자
  - 결론 세 가지를 세로 선택지로 둡니다: 위반 확정 / 정당한 업무 사용 / 탐지 오류. 고른 선택지는 파란 테두리 + 선택 면입니다.
  - **원인은 '위반 확정'일 때만 고릅니다.** 선택지는 '개인정보가 들어간 줄 모르고 보냄'과 '업무상 필요 없이 보냄' 두 가지입니다.
  - '정당한 업무 사용'은 원인을 묻지 않습니다. 대신 '재발 방지 — 같은 입력은 다음부터 자동 변환' 규칙 상자가 나옵니다.
  - '탐지 오류'에는 '탐지 제외에 추가' 상자가 나옵니다.
  - 판단 근거는 반드시 적어야 합니다.

## 6. 화면 구성

### 왼쪽 사이드바 (폭 232, `#1A1D21`, 오른쪽 경계 `#3A4148`)

- **위**: 로고 마크(22px, 파랑) + 'AI 누리 보안'(16/600), 그 아래 찾기 칸('찾기 ⌘K', 높이 32)
- **메뉴 6개**: 작업판 · 위반 검토 · 오탐 신고 · 변환 정책 · 배포·PC · 현황
  - 항목은 높이 32, 16px 아이콘에 14px 회색 글자입니다.

- 원문 노출, 마감·SLA·심각도·담당자·결재 기능
