# KP Guard (프로토타입)

생성형 AI(Claude Code, Codex CLI, IDE 터미널, 명령 프롬프트, 웹 채팅)에 프롬프트를 보내기 전에
개인정보·기밀정보를 찾아 가려 주는 도구. 탐지·가명화·기록·답변 복원은 **팀 서버(backend)**가 하고,
이 PC의 앱은 감시·화면·조직 베이스 확인을 맡는다. 서버로 보내지 않는 "이 PC에서만 처리" 모드도 있다.

> 지금은 **일반 사용자용 GUI 흐름 확인용**이다. UI는 이후 교체한다. 작업 목록: `.kiro/specs/kp-guard/tasks.md`

## 실행

```powershell
pip install -r requirements.txt     # 선택: 트레이 아이콘, 파일 검사, 소형 모델 실행 모듈 (없으면 그 기능만 꺼짐)
python -m agent.main                 # 설정 창과 함께 시작
pythonw kp_guard.pyw --background    # 창 없이 트레이에 상주 (자동 시작이 쓰는 방식)
```

첫 실행 때 "Windows 로그인 시 자동 실행" 여부를 묻는다. 설정 창에서 언제든 켜고 끌 수 있다
(`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\KPGuard`, 관리자 권한 불필요).

## 처리 위치: 서버 (기본) / 이 PC

설정 창의 "처리 위치"에서 고른다. 기본은 서버이고 주소는 `http://13.193.207.69:8501`(팀 backend)이다.
주소는 설정 창이나 `KPGUARD_SERVER_URL` 환경 변수로 바꾼다.

| 하는 일 | 서버 처리 | 이 PC에서만 처리 |
|---|---|---|
| 개인정보 탐지·가명화 (`[이름_1]` 같은 자리표시) | 서버 `POST /process` | 이 PC 엔진 (가짜 값으로 바꿈) |
| 사용자 선택 기록 (변환문 전송·원문 전송·취소, 사유) | 서버 `POST /process/decide` | 이 PC 로그만 |
| AI 답변 복원 | 서버 `POST /process/restore` | 이 PC 매핑 |
| 조직 베이스(코드네임·고객사·사내 도메인) | **서버로 보내기 전에 이 PC에서 태그로 바꿈** | 이 PC |
| 기밀 표기·사내 소스코드 차단 | 이 PC (서버 SLM 기밀 탐지와 함께 쓰는 안전망) | 이 PC |
| 복사한 글을 창에 띄울지 판단 | 이 PC 규칙·사전 (복사한 모든 글을 서버로 보내지 않기 위해) | 이 PC |
| 파일 검사 (엑셀 보호본) | 서버 `POST /files/sanitize` → `GET /files/{work_id}/download` (조직 베이스·기밀 표기는 이 PC에서 먼저) | 이 PC |

서버 처리 점검 창은 서버 결과를 원문과 맞춰 하이라이트하고, 항목별 되돌리기·놓친 정보 신고를 보낼 글에 반영한다.
서버가 위치를 돌려주지 않으므로 원문 위치는 앱이 맞춰 찾는다. 위치가 하나로 정해지지 않는 항목은 되돌리기를 막는다.

- **서버 작업은 `/process` 시점부터 10분 동안만 남고, 답변 복원은 한 번만 된다** (backend `app/sessions.py`)
- 서버 `/health`가 알려 주는 탐지 범위(모델+규칙 / 규칙만, 기밀 탐지 SLM 준비 여부, backend#11)를 설정 창에 보여 준다.
  규칙만인 서버에는 처음부터 규칙만 모드로 보내고(글을 두 번 보내지 않음) "이름·주소 미검사"라고 표시하며, 파일은 보내지 않는다.
  탐지 범위를 알려 주지 않는 이전 서버는 400(`LOCAL_PII_MODEL_DIR`)을 받은 뒤 규칙만 모드로 다시 요청한다
- 서버에 닿지 않으면 점검 창에서 "이 PC에서 검사"로 같은 글을 이 PC 엔진으로 검사할 수 있다
- **지금 서버는 HTTP(암호화 없음)이고 인증이 없다.** 앱은 점검 창과 설정 창에 경고를 띄운다. 실제 개인정보로 쓰기 전에 HTTPS와 토큰 인증이 필요하다

## 탐지 단계 (이 PC에서 처리할 때)

| 단계 | 내용 | 켜지는 조건 |
|---|---|---|
| 0 규칙 | 주민·카드·계좌·전화·이메일·IP·API 키 (검증식·문맥 점수) | 항상 |
| 1 사전·베이스 | 이름(성씨+호칭)·나이·주소·학교, 조직 베이스(코드네임·고객사·내부 도메인), 기밀 표기·사내 소스코드 | 항상 |
| 2 소형 모델 | AEGIS ONNX 개인정보 모델 (팀 backend `local_ai`): 이름·주소·생년월일·신분증 번호·계정 등 | 모델 폴더를 지정했을 때 |
| 2 SLM | 미세조정 GLiNER (팀 `slm` 레포): 회사 기밀 구간·코드네임 | 모델 파일을 받은 뒤 ONNX로 변환해 연결 예정 |

**소형 모델(AEGIS) 켜기.** 모델 파일은 레포와 exe에 들어 있지 않다. 아래 파일이 든 폴더를
설정 창의 "모델 폴더 선택…"으로 지정하거나 `%LOCALAPPDATA%\KPGuard\models\aegis`에 넣으면 다음 실행부터 켜진다.

```
model.onnx (또는 model_quantized.onnx, onnx/model_quantized.onnx)
tokenizer.json
config.json   (id2label)
```

- 모델은 백그라운드에서 불러오고, 준비되기 전에는 규칙·사전만으로 검사한다. 점검 창 오른쪽 위에 검사 범위가 나온다.
- 모델 추론이 실패하면 그 글은 "규칙·사전만"으로 표시하고 경고한다. 파일 검사는 보호본을 만들지 않는다.
- 확률이 0.6 미만인 모델 결과는 바로 바꾸지 않고 밑줄(확인 필요)로 보여 준다.
- 이름·주소 끝에 모델이 함께 잡은 조사("김민수의")는 팀 서버와 같은 규칙으로 뗀다(backend#12). 덜 떼는 쪽이라
  세 글자 이름 뒤 '이'·'가'("김민준이")는 이름 끝 글자일 수 있어 그대로 둔다.
- onnxruntime은 CPU로 실행하고 실행 중에 모델을 내려받지 않는다. 토크나이저도 폴더의 `tokenizer.json`만 읽는다.
  onnxruntime(1.31.1에서 확인)은 `disable_telemetry_events()`를 불러도 추론 중 `mobile.events.data.microsoft.com`으로
  연결을 시도해서, 앱은 진입점(`agent/main.py`)과 모델 모듈에서 onnxruntime을 불러오기 전에 `ORT_DISABLE_TELEMETRY=1`을 넣는다
  (backend#13과 같은 방식). 90초 동안 추론해 연결 시도 0회를 확인했고, 새 인터프리터에서 값을 확인하는 테스트가 있다.

## 파일 검사 (엑셀 보호본)

`Ctrl+Alt+F`, 트레이 메뉴, 설정 창에서 연다. `.xlsx`를 고르면 팀 backend `file_sanitizer`로 표를 읽고,
칸마다 점검 창과 같은 엔진으로 가린 **보호본**을 만든다. 원본 파일은 바꾸지 않는다.

- 숨긴 시트·행·열, 메모, 문서 속성, 파일 이름, 숫자 서식 문구까지 검사한다. 보호본에는 보이는 값만 남는다
- "홍길동 학생" 칸에서 이름으로 확인한 값은 문맥이 없는 다른 칸의 "홍길동"도 함께 가린다
- 프롬프트와 같은 매핑을 써서 AI 답변의 가짜 값을 답변 복원 창에서 되돌릴 수 있다
- 기밀 표기가 있으면 파일 전체를 차단한다. 보호본을 다시 읽어 가린 값이 남았으면 보호본을 내놓지 않는다
- 수식·매크로·차트·병합 셀·필터 등은 아직 지원하지 않는다 (값만 남긴 표로 저장해서 다시 검사)
- 로그에는 유형·건수만 남는다

**서버 처리일 때** (업로드 → 결과 → 보호본 받기, `agent/files/remote.py`)

1. 이 PC: 숨긴 시트·행·열, 메모, 문서 속성을 빼고 조직 베이스를 태그(`[프로젝트A]` 등)로 바꾼 사본을 만든다.
   기밀 표기·사내 소스코드가 있으면 여기서 막고 서버로 보내지 않는다. 원래 파일 이름 대신 `upload.xlsx`로 올린다
2. 서버(`POST /files/sanitize`): 개인정보를 `[이름_1]` 같은 자리표시로 바꾼 보호본을 만든다. 다른 파일을 처리 중이면(429) 잠시 기다렸다 다시 보낸다
3. 이 PC: 보호본을 바로 받는다(`GET /files/{work_id}/download`, 서버는 한 번만 내준다). 메모리에만 두고 "보호본 저장"으로 쓴다.
   서버 응답에는 무엇을 가렸는지가 없어서, 올린 사본과 받은 보호본을 칸끼리 맞춰 유형·개수를 센다.
   올린 사본에 없던 칸·숨은 내용, 이 PC에서 가린 값·기밀 표기가 보호본에 있으면 쓰지 않는다
4. 서버에 모델이 없거나(503) 닿지 않으면 "이 PC에서 검사"로 같은 파일을 이 PC 엔진으로 검사할 수 있다

- 파일의 서버 자리표시는 아직 답변 복원이 안 된다 (서버에 파일 복원 API가 없다, backend#29). 조직 베이스 태그는 이 PC에서 복원된다
- 프롬프트와 파일은 서버에서 자리표시 번호를 따로 매긴다. 프롬프트 복원에서 최근 1시간 안에 받은 파일 보호본과
  같은 자리표시를 바꾸면 "확인이 필요해요"로 알린다 (파일 쪽 값이었다면 틀린 값이다)
- 서버 파일 API는 기록을 남기지 않으므로 파일 검사 기록은 이 PC 로그에 남긴다 (backend#32)

## 데스크톱 앱 빌드

백그라운드에 상주하면서 프롬프트를 PC 안에서만 처리하고 기업 PC에 설치해 쓰는 도구라서, 웹 배포 없이 Windows 데스크톱 앱으로 배포한다.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

결과물은 `dist\KPGuard\` 폴더이고 `KPGuard.exe`로 실행한다 (트레이 상주는 `KPGuard.exe --background`).
배포할 때는 폴더째 복사한다. 자동 시작은 exe의 현재 경로를 등록하므로, 폴더를 옮기면 설정 창에서 자동 시작을 껐다 다시 켠다.
exe에는 onnxruntime 등 실행 모듈만 들어가고 모델 파일은 들어가지 않는다 (위의 "소형 모델 켜기" 참고).

## 화면 디자인

다크 디자인 설정(보안팀 콘솔 v17과 같은 토큰)을 `agent/gui/theme.py`에 옮겼다.

- 거의 검정 바탕(#131416)에 아웃라인으로 경계를 만들고, 대화상자·툴팁처럼 떠 있는 표면만 한 단계 밝힌다
- **앰버(#F6A623)는 창마다 '지금 처리할 한 곳'에만** 쓴다: 주요 버튼 하나와 토스트. 선택 표시는 회색
- 빨강·초록·노랑은 오류·성공·경고에만 쓰고 문구와 함께 쓴다. 점검 창 배너: 공개=초록, 민감=노랑, 기밀·오류=빨강
- 원문 쪽 하이라이트는 가린 원문 표시(빨강), 변환문 쪽 바꾼 값은 초록, 원문 그대로 나가는 값은 빨강 밑줄, 확인 필요는 노랑 밑줄
- 표·메뉴·툴팁의 원문 값은 일부만 보여 준다 (`홍*동`, `01*-****-**78`)
- 켜기·끄기는 스위치, 두 갈래 선택은 세그먼트, 버튼·입력은 알약 모양. 아이콘 대신 글자를 쓴다
- 글꼴은 Pretendard를 앱에 넣어 두었다(`agent/assets/fonts`, SIL OFL 1.1, `Pretendard-LICENSE.txt`).
  Windows에서 이 프로세스에만 등록해 쓰고, 없으면 맑은 고딕으로 바뀐다
- tkinter에 없는 것: 자간 조절, 숫자 폭 고정(tabular-nums), 그림자, 반투명. 반투명 토큰은 바탕색에 미리 섞었고,
  둥근 모서리는 Canvas로 그린다(Windows에서는 가장자리가 조금 거칠 수 있다). 크기는 화면 배율(DPI)에 맞춰 키운다

## 흐름

1. 백그라운드 상주 (트레이 아이콘: 초록=감시 중, 주황=일시정지, 회색=꺼짐)
2. 트리거
   - CLI·IDE·메신저 등 어디서든 프롬프트를 **복사**하면 자동 점검 → 민감정보가 있으면 점검 창이 뜬다
   - `Ctrl+Alt+P`: 빈 점검 창을 열고 프롬프트를 직접 작성
   - `Ctrl+Alt+F`: 엑셀 파일 검사 (보호본 만들기)
3. 점검 창: 왼쪽 원문(수정 가능) / 오른쪽 변환문, 유형별 하이라이트
4. **하이라이트(또는 표의 행) 클릭 → 사용자 행동**
   - 되돌리기 + 사유 (오탐 / 업무상 필요 / 승인받음 / 선택 안 함)
   - 다시 가리기, 변환 방식 바꾸기 (대체·일반화·삭제·태그)
   - 이 값은 앞으로 탐지하지 않기 (오탐 등록)
   - 기밀(빨간색): 이 부분 빼고 보내기 / 차단 해제(사유)
   - 밑줄 항목 = 확인 필요(자동 변환 안 함), 클릭해서 가리기
5. 놓친 정보: 원문에서 드래그 → 우클릭 → "이것도 가려줘"
6. **[변환문 복사]** → CLI에 붙여넣기 / [취소] / [원문 그대로 사용](사유 선택)
7. AI 답변을 복사하면 가짜 값이 있는지 확인해 **답변 복원 창**이 자동으로 뜬다 (`Ctrl+Alt+R`로 직접 열기)
8. 행동은 큐로 분류돼 로그에 남는다 (원문 없음): `%LOCALAPPDATA%\KPGuard\events.db`, `logs\YYYY-MM-DD.jsonl`

트레이 메뉴의 "예시로 점검해보기"에서 상담 안내문·코드네임·API 키·사내 소스코드·공개 질문 예시를 바로 열 수 있다.

## 구조

```
agent/
├─ main.py                 진입점 (단일 인스턴스, DPI)
├─ config.py               설정·경로·데모 조직 베이스
├─ detect/                 rules(0단계) · lexicon(1단계 경량) · model(2단계 AEGIS ONNX) · scoring(등급·조합 위험) · pipeline
├─ sanitize/               engine(전략·치환·문장 정리) · fakes · josa(조사 보정) · restore(답변 복원)
```

## 프로토타입 한계

- 기본 탐지는 정규식 + 작은 사전. 소형 모델(AEGIS)은 모델 파일을 지정해야 켜지고, 실제 모델로는 아직 측정하지 않았다
  (CPU 실행만, INT8 변환·NPU는 Phase 4). SLM(기밀 구간)은 모델 파일을 받은 뒤 연결한다
- 파일 검사는 값만 있는 `.xlsx`만 지원한다. docx·pptx·hwp·pdf는 Phase 2 남은 작업
- CLI 입력을 직접 가로채지 않고 클립보드로 연결한다. Claude Code 훅·CLI 래퍼는 P0.11
- 이 PC 처리의 매핑은 앱 메모리에만 있어 앱을 끄면 이전 답변은 복원할 수 없다 (의도된 동작).
  서버 처리의 매핑은 서버에 10분, 한 번 복원할 때까지만 있다
- 서버 처리는 실제 팀 서버(`13.193.207.69:8501`)로는 검증하지 못했다 (개발 환경에서 평문 HTTP 서버에 닿지 않음).
  같은 backend 코드(main `2042ae3`)를 로컬에서 띄워 검사·기록·복원·규칙만 모드를 확인했고,
  파일 검사는 main `4882ff0`(PR #17 보호본 다운로드)으로 업로드·한 번 받기·모델 없음(503)을 확인했다
- 모든 예시 값은 합성 데이터
- exe는 코드 서명이 없어 SmartScreen·백신 경고가 뜰 수 있고, 설치 프로그램은 아직 없다 (태스크 27)

## macOS 앱 빌드

macOS에서 Python 가상환경을 활성화하고 `pip install -r requirements.txt -r requirements-build.txt`를 실행한 뒤 `./build-macos.sh`로 `dist/KPGuard.app`을 만듭니다. 모델 파일은 앱에 포함되지 않으므로 별도로 로컬에 준비해야 합니다.

개발용 빌드는 서명 및 Apple 공증을 자동으로 수행하지 않습니다. 다른 Mac에 배포할 때는 개발자 인증서와 공증을 별도 준비하고 Gatekeeper 동작을 확인해야 합니다. 이 빌드는 실제 배포 환경에서 아직 검증되지 않았습니다.
