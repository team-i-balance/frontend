## 범위 조정 메모
- 대상 환경을 브라우저 확장뿐 아니라 **Claude Code / Codex CLI, IDE 터미널, 명령 프롬프트**까지 넓힌다.
- CLI·IDE에는 입력창을 가로챌 DOM이 없으므로, 프로토타입은 **클립보드 감시 + 전역 단축키**로 트리거한다.
  (프롬프트 복사 → 자동 점검 창 → 변환문 복사 → CLI에 붙여넣기)
- UI는 이후 교체 예정. 지금은 **일반 사용자용 흐름 확인**이 목적 (tkinter, 외부 의존성 없음).
