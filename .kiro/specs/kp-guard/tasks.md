# 구현 태스크

> 전체 스펙은 `.kiro/steering/project.md` 참고. 괄호 안 `§번호`는 스펙 문서 섹션.
> 우선순위: Phase 0(GUI 흐름 프로토타입) → Phase 1~3 공모전 필수 → Phase 4~5 조직 모드·고도화 → Phase 6 시연·마무리.
> 시간이 부족하면 줄이는 순서: 회피 탐지 → 이미지 OCR/블러 → 위험 확장 점검 → 보안팀 도구 UI(JSON 직접 편집으로 대체). **시뮬레이터는 반드시 유지.**

## 범위 조정 메모
- 대상 환경을 브라우저 확장뿐 아니라 **Claude Code / Codex CLI, IDE 터미널, 명령 프롬프트**까지 넓힌다.
- CLI·IDE에는 입력창을 가로챌 DOM이 없으므로, 프로토타입은 **클립보드 감시 + 전역 단축키**로 트리거한다.
  (프롬프트 복사 → 자동 점검 창 → 변환문 복사 → CLI에 붙여넣기)
- UI는 이후 교체 예정. 지금은 **일반 사용자용 흐름 확인**이 목적 (tkinter, 외부 의존성 없음).
